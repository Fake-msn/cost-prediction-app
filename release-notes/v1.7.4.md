# v1.7.4 — 部署体验修复版

> 发布日期: 2026-08-03

修复新设备通过 start.bat 启动失败的编码问题，并将已训练模型集成进发布包（新设备克隆即用，无需重训）。

## 问题修复 (Bug Fixes)

### 启动脚本编码

- **start.bat / push.bat / setup-gitee-mirror.bat 全 ASCII 化**
  - 根因：脚本原为 UTF-8 编码且含中文，cmd.exe 按系统代码页（中文 Windows 默认 GBK/936）解析批处理文件，中文行乱码并被当作命令执行，报 `'xxx'不是内部或外部命令`；文件内 `chcp 65001` 无法修复已读入的批处理内容。
  - 修复：全部输出改为纯英文 ASCII，任何代码页 / 系统语言下 100% 兼容。

### requirements.txt 编码

- 根因：中文注释导致 pip 在 GBK 代码页下读取依赖清单时 `UnicodeDecodeError` 崩溃，新设备 pip install 必然失败。
- 修复：注释改为 ASCII 英文。

### .gitignore 编码

- 原文件中文注释区域为损坏字节（双重编码损坏），已重写为纯 ASCII 并去除损坏内容。

## 改进优化 (Improvements)

### 启动健壮性

- Python 3.11+ 版本检查（替代脆弱的 `--version` 判断）。
- `models_cache` 模型存在性检查（缺失时报错退出，避免无模型启动）。
- 服务异常退出时 `pause` 保留错误信息（窗口不再闪退）。

### 模型文件集成发布包

- `models_cache` 的 8 个已训练模型（共 3.31MB）随仓库分发。
- 新设备克隆后直接预测，无需重新训练；训练数据与 DuckDB 亦已在仓库中。
