# v1.10.0 — 首页无障碍增强 + DuckDB 正式切换到 2.0.0 GA

> 发布日期: 2026-10-27

## 新增特性 (Features)

### 前端首页 — 无障碍（a11y）增强 + 移动端导航
- **ARIA 语义结构**: 首页导航补齐 `role="banner"` / `role="navigation"` / `aria-label`（主导航、导航菜单），logo 装饰标记加 `aria-hidden="true"`，提升屏幕阅读器可理解性。
- **移动端汉堡菜单**: 新增 `hamburger-btn`（`aria-label`、`aria-expanded`、`aria-controls` 联动）与全屏 `mobile-nav` 抽屉（`role="dialog"` + `aria-modal`），小屏下可开合主导航，覆盖功能特性 / 使用流程 / 定价方案 / 开始使用入口，避免移动端导航不可用。

## 改进优化 (Improvements)

### 依赖与运行时 — DuckDB 正式切换到 2.0.0（本次核心）
- **依赖锁定**: `backend/requirements.txt` 与 `deploy/modelscope/requirements-ms.txt` 的 DuckDB 由 `>=1.5.6,<2.0` 升级为精确 `==2.0.0`。DuckDB 2.0.0 稳定版已于 2026-10-21 发布，命中升级 runbook §5 的切换门控（"2.0 稳定版非 dev 发布"）。
- **切换前实测（生产库副本，未触碰本体）**: 2.0.0 对现有 `v1.5.5` 库读写 + CHECKPOINT 后存储令牌仍为 `v1.5.5`、**未抬升**；1.5.5 对被 2.0.0 写过的副本只读/读写均可 → **回滚门敞开，回滚无需还原数据文件**。
- **兼容性零差异**: `duckdb2_compat_audit.py` 在 2.0.0 与 1.5.5 下各 15/15 PASS，归一化后逐行一致；`backend/tests_integration/`（真实引擎、非 mock）12/12 全绿；`migrate_duckdb_v2.py` verify + checkpoint 逐表行数/列签名不变。
- **CI 门禁同步**: 真实 DuckDB 引擎审计/集成测试步骤的注释由 "pin <2.0" 更新为 "pin ==2.0.0，已 GA"；仍严禁 `pip --pre`，只装稳定版。

### 仓库卫生
- **忽略 AI 工具链重复产物**: `.gitignore` 扩充，减少各类 AI 编辑器/代理目录误入版本库；补充 `AGENTS.md` 与 skills 相关产物纳管。

## 破坏性变更 (Breaking Changes)

- **DuckDB 依赖精确锁定到 2.0.0**: 升级后需重新安装依赖（`start.bat` / `start.sh` / Docker 构建会自动处理）。**数据格式无破坏性变更**——现有库文件仍为 `v1.5.5` 兼容令牌，1.5.6 可随时降级接手。唯一注意事项（见 runbook §8）：运行时已是 2.0.0，**不要**用 2.0 从零重建生产库后再回退到 1.5.x（新建库令牌会是 `v2.0.0`，1.5.x 打不开）。
