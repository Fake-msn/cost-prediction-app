# v1.8.0 — 多栋建筑全链路 + 一键部署 + DuckDB 稳健

> 发布日期: 2026-08-02

## 新增特性 (Features)

### 多栋建筑组合体支持（全链路）
- **DuckDB 表结构扩展**: `project_meta` 新增 5 列——`building_count`、`buildings_json`、`max_floor`、`min_floor`、`mixed_types`，支持存储多栋建筑的楼层分布、类型和面积信息。
- **源数据自动识别**: `extract_boq.py` 新增 `parse_buildings_from_unit_names()`，从 Excel 表-08 工作表名（单位工程名）中自动解析各栋楼层数和建筑类型，支持 `#` 编号格式（如 `10#楼`）和范围表达式。
- **模型多栋特征学习**: `ml_models.py` 新增 `extract_multi_building_features()`，提取 `building_count`、`floor_std`、`residential_ratio`、`commercial_ratio`、`mixed_types`、`avg_floor` 共 6 个组合特征；`scale_factor` 引入楼层分布复杂度修正和多栋混合类型修正。
- **API 接口扩展**: 新增 `BuildingItem` Pydantic 模型，`ProjectRequest.buildings` 可选数组字段支持 `[{floors, area, type, basement}]` 格式，完全向后兼容单栋模式。
- **前端动态建筑 UI**: 预测引导界面新增"多栋建筑"板块，支持动态添加/删除各栋建筑，分别设置楼层数、建筑类型、面积和地下层数；提交时校验各栋面积之和与总面积的匹配度（容差 1%）。
- **对话智能体引导**: `agent.py` 在检测到"栋/楼栋/小区/组团"等关键词时，主动引导用户提供各栋建筑的详细参数。

### 部署自动化
- **一键启动脚本全面升级**: `start.bat`（Windows）和 `start.sh`（Linux/macOS）支持自动检测 Python 版本（需 ≥3.11）、按操作系统自动安装（winget/brew/apt/dnf/yum/zypper）、自动创建虚拟环境并安装依赖。
- **Python 安装引导**: 优先展示 python.org 官方下载链接，winget 降为需手动确认的备选方案。
- **服务崩溃自动诊断**: 服务异常退出时自动显示 4 类常见故障及对应修复命令。
- **DuckDB 完整性保护**: 启动前检测数据库可读性，损坏时需手动输入 `DELETE` 确认才删除（防止 25 倍训练数据丢失）。

### 数据管线
- **DuckDB 重建管线**: `init_duckdb.py` → `migrate_to_duckdb.py` → `extract_boq.py` → `cost_breakdown_extractor.py` 完整执行并验证。
- **费用构成批量提取**: `cost_breakdown_extractor.py` 从 50+ 个源项目文件中提取 71 个项目的分部分项费用和人工费数据。

### CI/CD
- **GitHub Actions 自动发布**: 推送 `v*` 标签时自动提取 commit 摘要并创建 GitHub Release。
- **结构化 Release Notes 支持**: 优先读取 `release-notes/${{ github.ref_name }}.md` 作为发布正文。

## 问题修复 (Bug Fixes)

### cost_breakdown_extractor.py
- **修复 SQL INSERT 参数计数不匹配**: VALUES 子句 26 个 `?` 占位符 vs 25 个实参值，导致所有费用构成写入失败。
- **修复 GBK 终端 Unicode 编码错误**: emoji 打印在中文 Windows 终端崩溃，改用 ASCII `[OK]`/`[FAIL]` 标记。
- **修复名称匹配阈值过严**: `find_source_excel()` 降级为至少 1 个长关键词匹配即可，71/152 项目成功关联源文件。

### document_parser.py
- **修复 Tesseract 路径跨平台硬编码**: `C:\Program Files\Tesseract-OCR\tesseract.exe` 仅在 Windows 平台设置，Linux/macOS/Docker 依赖系统 PATH 自动查找。

### start.bat
- **修复终端闪退**: 6 个错误退出点全部添加 `pause >nul`，Python 版本检测失败时不再静默关闭窗口。
- **修复 winget 安装旧版 Python**: 引导用户优先使用 python.org 官方安装包，winget 降为需手动确认的备选方案。

### Dockerfile
- **删除冗余 `pip install xgboost`**: `requirements.txt` 已包含该依赖，删除重复安装行。

### app.js
- **新增多栋建筑面积校验**: 各栋面积之和与 `total_area` 偏差超过 1% 时阻止提交并提示。

## 改进优化 (Improvements)

### 启动体验
- `start.bat` 新增 Tesseract 中文语言包 `chi_sim` 检测（不阻塞启动，仅警告）。
- `start.bat` 新增 DuckDB 完整性检测，成功后展示文件大小和关键表行数。
- `main.py` 首次数据导入时输出进度日志（消除"黑屏等待"体验）。

### 数据保护
- `data/cost_prediction.duckdb` 从 Git 跟踪中移除（`git rm --cached`），不再随仓库分发，首次启动自动从 Excel 训练数据重建。

### 新用户引导
- 新增 `.env.example` 模板，包含 5 个 LLM provider（DashScope/OpenAI/Anthropic/Gemini）的 API Key 配置指引。
- 启动脚本末尾追加 API Key 配置提示。

### 代码质量
- 所有 `pip install` 改为 `python -m pip install` 显式调用，移除 `-q` 静默参数以展示安装进度。
- `migrate_to_duckdb.py` 支持从 Excel "栋数"列自动填充 `building_count` 和多栋 JSON。

## 破坏性变更 (Breaking Changes)

- **DuckDB 不再随仓库分发**: `data/cost_prediction.duckdb` 已从版本控制中移除。`git clone` 后首次运行 `start.bat`/`start.sh` 会自动从 Excel 训练数据重建数据库（约需 1-2 分钟）。
- **Python 最低版本要求**: 启动脚本严格校验 `sys.version_info >= (3, 11)`，低于此版本的 Python 将无法通过检测。
