使用 AgentScope SDK 构建的专业建筑工程造价预测 ReAct 智能体应用

核心功能

覆盖从数据训练到造价预测的完整工作流

🧠

ReAct 智能体对话

基于 AgentScope SDK 的 ReAct 推理模式，自然语言输入项目参数即可获取造价预测。支持意图识别、参数提取、工具调用全流程。

📊

三层模型预测

总造价预测（PSO-SVR/GBT）、分部分项工程（XGBoost）、清单项目（RF/Apriori/LR）三层融合预测，加权平均输出。

📋

三阶段造价支持

估算阶段（7参数，±20%）、概算阶段（32参数，±10%）、预算阶段（35参数，±3%），精度逐级提升。

🏗️

六层级成本分解

项目总造价→单项工程→单位工程→分部工程→分项工程→明细级别，逐层细化成本构成。

📥

Excel 批量训练

支持 .xlsx/.xls 格式历史项目数据批量导入，自动校验字段，训练后模型具备新项目造价评估能力。

💬

结构化结果展示

侧边栏历史会话切换、对话式主交互、向导式五步流程、可视化费用构成条形图、可导出 JSON/HTML 报告。

术语规范

建筑造价术语严格遵循《建设工程"五算"解析》

估算（投资估算）
项目建议书和可行性研究阶段，基于类似工程经验的初步投资测算，误差率 ±20%，精度 70-80%
概算（设计概算）
初步设计阶段，以设计图纸、概算定额为依据编制的投资测算，误差率 ±10%，精度 80-90%
预算（施工图预算）
施工图设计阶段，按《建设工程工程量清单计价规范》详细计算，误差率 ±3%，精度 95%+
工程量清单计价法
依据《建设工程工程量清单计价规范》计算，使用国有资金的项目必须采用
直接工程费
直接构成工程实体的费用，含人工费、材料费、机械费、措施费
间接费
建筑安装企业组织施工生产和经营管理所需费用，含企业管理费、规费
