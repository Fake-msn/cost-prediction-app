# v1.7.3 — 依赖安全修复版

> 发布日期: 2026-08-03

修复 GitHub dependabot 检测到的 12 个依赖漏洞（8 个 python-multipart + 4 个 Jinja2），其中包含 3 个 high 级别漏洞。

## 问题修复 (Bug Fixes)

### 依赖安全

- **python-multipart 0.0.9 → 0.0.31**（8 个漏洞，含 3 high）:
  - GHSA-5rvq-cxj2-64vf（high）CPU 二次方 querystring 解析 DoS
  - GHSA-pp6c-gr5w-3c5g（high）无界 multipart part headers DoS
  - GHSA-59g5-xgcq-4qw3（high）畸形 multipart boundary DoS
  - GHSA-wp53-j4wj-2cfg（high）非默认配置下任意文件写入
  - GHSA-mj87-hwqh-73pj（medium）大 preamble/epilogue 数据 DoS
  - 4 个 low（参数走私 / 负 Content-Length 内存缓冲）
- **jinja2 3.1.3 → 3.1.6**（4 个 medium）:
  - GHSA-cpwx-vrp4-4pq7 / GHSA-gmj6-6f8f-6699 / GHSA-q2x7-8rv6-6q7h sandbox breakout
  - GHSA-h75v-3vvj-5mfj xmlattr HTML 属性注入

## 说明

- python-multipart 是文件上传功能（`/api/predict/upload`、`/api/chat/upload`、`/api/data/import`）的核心依赖，8 个漏洞直接威胁上传端点，已全部修复。
- jinja2 在代码中未直接使用（仅声明依赖），升级以消除告警。
- 本次修复与 dependabot 自动 PR #4 合并（rebase 线性历史）。
